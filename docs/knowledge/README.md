# BigBrain Knowledge Base

## Syfte

Samla återanvändbar, evidensbaserad projektkunskap utan att göra incidentrapporter till odaterad runtime-sanning.

## Verifierade fakta

- Kunskapsfiler sammanfattar kod, normativa dokument och daterad evidens.
- Dynamiska värden, identiteter och tjänstestatus ska alltid verifieras live.

## Viktiga tekniska lärdomar

- Märk fakta som projektkunskap, versionsspecifik observation, historisk incidentlärdom, rekommendation eller ej verifierat.
- Följ dokumentauktoriteten i [dokumentationsindexet](../indexes/documentation.md).

## Vanliga feltolkningar

- En kunskapsfil är varken ADR, runbook eller runtime-baseline.
- Senare datum ersätter inte automatiskt ett annat dokuments scope.
